# 03 — Standar Istilah dan Notasi

**Satu istilah = satu kata, dipakai sama di ke-36 modul.** Anak bingung bukan karena materinya sulit, tetapi karena Senin disebut "gagasan utama" dan Jumat disebut "ide pokok". **[FAKTA — *Tahap 2B*]** Mathnasium mewajibkan instrukturnya memakai istilah baku dengan alasan persis ini.

Aturan baca tabel:
- Kolom **Dipakai** = satu-satunya kata yang boleh ditulis dan diucapkan.
- Kolom **Jangan dipakai** = sinonim yang dilarang, **termasuk saat pengajar berbicara**.
- Istilah Inggris hanya muncul di **berkas induk dan petunjuk untuk pengajar**, dalam kurung, sekali saja. **Tidak pernah di lembar anak.**

## 2. Bentuk soal

| Dipakai (lengkap) | Singkatan di berkas pengajar | Kalimat perintah baku di lembar anak |
|---|---|---|
| **pilihan ganda** | PG | "Pilih satu jawaban yang benar." |
| **pilihan ganda kompleks** | PG kompleks | "Pilih **semua** jawaban yang benar. Jawaban benar bisa lebih dari satu." |
| **pilihan ganda kategori** | PG kategori | "Tentukan **Benar** atau **Salah** untuk setiap pernyataan." |

**Jangan dipakai:** "multiple choice", "PGK", "benar-salah" (sebagai nama bentuk), "isian", "uraian", "jodohkan".

**Aturan tulis:**
- Pilihan PG dan PG kompleks diberi huruf **A, B, C, D** (PG kompleks boleh sampai **E**).
- PG kategori ditulis sebagai **tabel** berkolom `Pernyataan | Benar | Salah`, berisi 3–4 pernyataan.
- Perintah PG kompleks **tidak** menyebut jumlah jawaban benar ("pilih dua" dilarang). Ini sesuai bentuk TKA **[ASUMSI — PERLU DICEK di "Ayo Coba TKA"]**.

## 3. Matematika — Bilangan

| Dipakai | Definisi baku (kalimat untuk anak) | Jangan dipakai |
|---|---|---|
| **bilangan cacah** | 0, 1, 2, 3, dan seterusnya | bilangan bulat positif (untuk SD) |
| **operasi hitung campuran** | Soal yang memuat lebih dari satu jenis operasi | operasi gabungan |
| **urutan pengerjaan** | (1) dalam kurung, (2) kali dan bagi dari kiri, (3) tambah dan kurang dari kiri | "kabataku", "kukabataku", jembatan keledai lain |
| **faktor** | Bilangan yang membagi habis suatu bilangan. "Faktor dari 12 adalah bilangan yang bisa membagi 12 tanpa sisa." | pembagi (boleh sebagai penjelasan, bukan istilah) |
| **kelipatan** | Hasil kali bilangan itu dengan 1, 2, 3, … "Kelipatan 4 adalah 4, 8, 12, 16, …" | perkalian dari |
| **bilangan prima** | Bilangan yang tepat punya dua faktor: 1 dan dirinya sendiri | angka prima |
| **faktorisasi prima** | Menulis bilangan sebagai perkalian bilangan prima | pohon faktor (itu **alat**, bukan istilahnya — boleh disebut "pohon faktor" sebagai nama gambar) |
| **FPB** | **Faktor Persekutuan Terbesar**. Faktor sama yang paling besar | faktor terbesar, PBT |
| **KPK** | **Kelipatan Persekutuan Terkecil**. Kelipatan sama yang paling kecil (selain 0) | kelipatan terkecil, LCM |
| **pecahan** | Bilangan yang ditulis a/b | angka pecahan |
| **pembilang** | Bilangan di atas garis pecahan | angka atas |
| **penyebut** | Bilangan di bawah garis pecahan | angka bawah |
| **pecahan senilai** | Pecahan yang nilainya sama walau angkanya berbeda | pecahan sama, pecahan ekuivalen |
| **menyederhanakan pecahan** | Membagi pembilang dan penyebut dengan FPB-nya | meringkas, memperkecil |
| **pecahan biasa** | Pecahan a/b | pecahan murni |
| **pecahan campuran** | Bilangan cacah + pecahan, misalnya 2 1/2 | pecahan bersusun |
| **menyamakan penyebut** | Mengubah pecahan agar penyebutnya sama | mencari penyebut persekutuan (boleh sekali di contoh jadi, lalu kembali ke istilah baku) |
| **desimal** | Bilangan berkoma, misalnya 0,75 | bilangan koma, pecahan desimal (boleh sekali di pengenalan M04) |
| **persen** | Per seratus, ditulis % | perseratus (sebagai istilah) |
| **membalik pecahan** | Menukar pembilang dan penyebut: 2/3 menjadi 3/2. Bentuk pasif "dibalik" boleh | kebalikan, invers |
| **penaksiran** | Menghitung perkiraan dengan bilangan yang sudah dibulatkan | tebakan, estimasi (boleh sekali di M13) |
| **pembulatan** | Mengubah bilangan ke puluhan/ratusan/ribuan/satuan terdekat | membulatkan ke atas (kecuali memang dimaksud) |
| **rasio** | Perbandingan dua banyak benda, ditulis a : b | ratio |
| **perbandingan senilai** | Kalau satu bertambah, yang lain bertambah dengan kelipatan sama | berbanding lurus |
| **perbandingan berbalik nilai** | Kalau satu bertambah, yang lain berkurang dengan kelipatan sama | berbanding terbalik |
| **skala** | Perbandingan jarak pada peta dengan jarak sebenarnya | perbandingan peta |

## 4. Matematika — Geometri & Pengukuran

| Dipakai | Definisi baku | Jangan dipakai |
|---|---|---|
| **satuan panjang** | km, hm, dam, m, dm, cm, mm | ukuran panjang |
| **satuan berat** | kg, hg, dag, g (+ ton, kuintal) | satuan massa (boleh disebut sekali untuk pengajar) |
| **satuan volume** | liter (L), mililiter (mL), cm³, dm³, m³ | satuan isi, satuan kapasitas |
| **tangga satuan** | Gambar tangga untuk naik-turun satuan | jembatan satuan |
| **jarak, waktu, kecepatan** | kecepatan = jarak : waktu | laju (kecuali di M10 bagian "laju perubahan"), speed |
| **laju perubahan** | Besar perubahan tiap satu satuan waktu (mis. air naik 2 cm tiap menit) | kecepatan perubahan |
| **keliling** | Panjang garis yang mengelilingi bangun | lingkaran luar, pinggiran |
| **luas** | Banyaknya persegi satuan yang menutupi permukaan bangun | lebar, isi |
| **alas** dan **tinggi** | Tinggi selalu **tegak lurus** alas | sisi miring (untuk tinggi) |
| **sisi**, **titik sudut** | Garis tepi bangun; titik pertemuan dua sisi | pojok, ujung |
| **sudut siku-siku** | Sudut 90° | sudut tegak |
| **sudut lancip / sudut tumpul / sudut lurus** | < 90° / antara 90° dan 180° / 180° | sudut tajam |
| **sudut berpelurus** | Dua sudut yang jumlahnya 180° | sudut bersebelahan |
| **sudut berpenyiku** | Dua sudut yang jumlahnya 90° | sudut komplemen |
| **kongruen** | Bentuk dan ukurannya sama persis | sama dan sebangun (untuk SD cukup "kongruen") |
| **bangun datar** | Persegi, persegi panjang, segitiga, jajargenjang, trapesium, layang-layang, belah ketupat, lingkaran | bidang datar |
| **bangun ruang** | Kubus, balok, prisma, tabung, limas, kerucut, bola | benda ruang |
| **rusuk** | Garis pertemuan dua sisi bangun ruang | garis, tepi |
| **sisi** (bangun ruang) | Bidang datar yang membatasi bangun ruang | muka, permukaan (untuk satu bidang) |
| **volume** | Banyaknya kubus satuan yang mengisi bangun ruang | isi, kapasitas |
| **luas permukaan** | Jumlah luas semua sisi bangun ruang | luas sisi, luas selimut (untuk kubus/balok) |
| **jaring-jaring** | Gambar sisi-sisi bangun ruang yang dibuka dan diratakan | pola bangun, bukaan |
| **bangun ruang gabungan** | Dua atau lebih bangun ruang yang ditempel | bangun ruang majemuk |
| **sisi yang berimpit** | Sisi yang menempel dan tidak terlihat dari luar | sisi yang tertutup |
| **tampak atas / tampak depan / tampak samping** | Gambar susunan kubus dilihat dari atas / depan / samping kanan | pandangan atas, view |

## 5. Matematika — Data

## 7. Notasi baku

| Hal | Ditulis | Jangan ditulis |
|---|---|---|
| Kali | **×** | x, *, · |
| Bagi | **:** | ÷, / (untuk operasi bagi) |
| Tanda desimal | **koma**: 0,75 | titik: 0.75 |
| Pemisah ribuan | **titik**: 12.500 | koma, spasi: 12,500 / 12 500 |
| Uang | **Rp12.500** (tanpa spasi, tanpa ,00) | Rp. 12.500,- / 12.500 rupiah (di soal) |
| Pecahan biasa | **3/4** | 3 per 4 (di tulisan) |
| Pecahan campuran | **2 1/2** (bilangan cacah, **satu spasi**, pecahan) — dibaca "dua satu per dua" | 2½ (tidak semua huruf punya), 21/2 |
| Persen | **25%** (tanpa spasi) | 25 % / 25 persen (di soal) |
| Rasio | **3 : 4** (spasi di kiri-kanan titik dua) | 3:4 / 3/4 (untuk rasio) |
| Skala | **1 : 500.000** | 1:500000 |
| Pangkat satuan | **cm²**, **cm³**, **m²** | cm2, cm^2, cm pangkat 2 |
| Satuan | spasi antara angka dan satuan: **12 cm**, **3 kg**, **250 mL**, **1,5 L** | 12cm, 250ml, 1,5 ltr |
| Liter / mililiter | **L** / **mL** | l / ml / ltr |
| Kecepatan | **km/jam**, **m/menit** | kpj, km per jam |
| Pukul (waktu kejadian) | **pukul 07.30** | jam 7.30, 07:30 |
| Lama waktu | **2 jam 15 menit** | 2:15, 2,15 jam |
| Derajat | **90°** | 90 derajat (di soal) |
| Suhu | **30°C** | 30 °C |
| Sama dengan | **=**, spasi di kiri dan kanan | tanpa spasi |
| Kurung | ( ) saja | [ ] { } |
| Titik-titik | **Tidak dipakai di soal** (bentuk isian) | … di akhir kalimat soal |
| Nama bangun di gambar | huruf kapital: **ABCD** | abcd |

**Satu hal yang sering terlewat:** di soal, **angka di bawah 10 yang tidak diikuti satuan ditulis dengan huruf** ("tiga anak"), kecuali di soal Matematika yang operasinya memakai angka itu ("3 anak mendapat …"). **Di soal Matematika selalu pakai angka.**

## 8. Kalimat baku pengajar — diucapkan apa adanya

| Momen | Kalimat |
|---|---|
| Aba-aba papan jawaban | "Tulis jawabanmu. Tutup papannya. … **Tunjukkan sekarang!**" |
| Jawaban salah (menunjuk letak) | "Lihat baris ini. Coba periksa lagi langkah ini saja." |
| Umpan balik pekerjaan | "Caramu menyamakan penyebut tadi tepat." (sebut **pekerjaannya**) |
| Anak macet | "Apa yang sudah kamu ketahui dari soal ini?" |
| Menunjuk giliran | "Sekarang giliran [nama]." (tanpa "siapa yang bisa?") |
| Memulai tiket keluar | "Tiga soal terakhir. Kerjakan sendiri. Ini untuk Kakak tahu bagian mana yang perlu kita ulang." |
| Menutup analisis kesalahan | "Kesalahan yang sudah kamu beri tanda adalah bagian yang akan kita kuatkan. Itu bagus." |
