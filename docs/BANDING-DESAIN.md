# Banding Desain

Kiri: gambar desain (`desain/gambar-layar/`). Kanan: aplikasi hasil build web, 360 × 800 (`docs/tangkapan/`).

Cara membuat ulang: lihat komentar di `scripts/tangkap-layar.cjs`. Galat konsol saat tangkapan: lihat `docs/tangkapan/galat.txt` (kosong).

Yang sudah diperbaiki setelah dibandingkan: pecahan tidak sejajar di web, kolom tabel TKA tidak lurus, ubin Tebak Kata terpotong, tab bawah tidak berpindah (galat navigasi).
