# Pinci — aplikasi Pintar Main

Aplikasi Android belajar untuk anak SD dan orang tuanya, dengan maskot **Pinci, Si Kancil Pintar**.

| Folder atau berkas | Isi |
|---|---|
| `PROMPT-RCTOR.md` | Perintah pembangunan untuk Claude Code (sekali jalan) |
| `CLAUDE.md` | Aturan tetap untuk setiap sesi Claude Code |
| `docs/rancangan/` | Rancangan sistem v1.4 (per berkas dan gabungan) |
| `desain/` | Desain dari Claude Design: 31 gambar layar dan sumbernya |
| `bahan/kursus-tka-sd/` | Paket Siap TKA SD (teks modul, simulasi, teks baca cepat, alat pemeriksa) |
| `bahan/purwarupa-lancar-v5/` | Purwarupa Latihan Hitung Cepat v5 dan Metode LANCAR |
| `arsip-flutter/` | Percobaan tahap 1 dengan Flutter, disimpan sebagai acuan (aplikasi dibangun dengan Expo) |

**Menjalankan pembangunan:** buka Claude Code web, pilih repo ini, lalu tempel isi `PROMPT-RCTOR.md` mulai dari `## R — ROLE`. Kalau terputus, ketik: "Lanjutkan pembangunan dari KEMAJUAN.md."
